«Оно тебе надо» — Аукцион вещей, в которые никто не верил
Одностраничный сайт веб-аукциона необычных лотов, созданный в рамках учебного проекта. Проект посвящён культовым вещам, фильмам и книгам, которые в своё время не получили признания критиков, но изменили современную культуру.

Технологии и особенности
* HTML5 / CSS3
* Семантическая верстка (`header`, `main`, `section`, `article`, `footer`, `address`)
* CSS Grid и Flexbox для создания адаптивной сетки и выравнивания элементов
* Кастомные шрифты и стилизация интерактивных элементов (ссылки, кнопки)

Структура проекта
```text
index.html      Главная страница сайта
styles/
style.css       Основные стили компонентов страницы
global.css      Глобальные стили, сброс стилей и базовые настройки
fonts/
fonts.css       Подключение шрифтов
images/         Изображения, иконки и логотипы
